Backbone Breach Viewer

Watch an assume-breach attack spread across a Topology Zoo backbone, one round at a time. At the start of each attack the attacker either holds a working exploit for each piece of software or not, with the chance set by its EPSS score; a held exploit works on every node running that software. Each newly compromised node then makes one attempt on every node it can reach, halved in strength for every link of distance beyond the first.

Model: independent cascade, decay mode, shared exploits, as in simulate.py. Per attack, the exploit for each package is held with probability q = max EPSS over its network-reachable foothold CVEs (code execution or access, not DoS or disclosure); a node's p is then 0.95 if held, else the 0.05 credential-reuse floor, so on average p = 0.05 + 0.90 × q. An attempt from a node d links away succeeds with p × 0.5^(d − 1); each attacker–target pair fires at most once. Configurations from data/configs; EPSS pulled 2026-10-12. Layouts use each node's real latitude and longitude where the Topology Zoo file has them for at least 80% of nodes; other networks are drawn schematically. "Sweep average" is the mean over 2,000 simulated attacks in results/sweep.csv.
